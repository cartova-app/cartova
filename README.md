## About Cartova

Cartova is an open-source, extensible e-commerce ecosystem designed to empower businesses of all sizes. Built with modern web technologies, it offers a seamless shopping experience for customers and a powerful management dashboard for merchants.

🌐 **Visit our official website:** [cartova.dev](https://cartova.dev)
